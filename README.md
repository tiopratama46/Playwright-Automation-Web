# Playwright-Automation-Web

🛠️ Tech Stack
Playwright – End-to-end testing framework
JavaScript (Node.js) – Test scripting language
Page Object Model (POM) – Design pattern for maintainable test structure
dotenv – Manage environment variables (.env)
Git & GitHub – Version control
Playwright HTML Reporter – Test reporting

## Structure Project 
[Structure](./assets/structure-project.png)

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Install Playwright 
   ```bash
   npx playwright install
   ```

## Run tests

- Run all tests:
  ```bash
  npm run test:report
  ```

## View report

- After running tests, view the HTML report:
  ```bash
  npm run test:report
  ```
  ![Report](./assets/report-automation.png)
